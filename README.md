# Motor-Cortex-EEG-PCB
Created this for my group capstone project from September 2025 to around April 2026

email me at jacobrubin.contact@gmail.com for any inquiries

This repo contains the PCB files for a motor cortex mu wave (or really any brain wave) amplifier that can read at the micro-volt level with relatively low noise, and then digitizes the signal to be sent over SPI to an arduino or other microcontroller.

Some parts are not listed in the files, but can be requested at my email
